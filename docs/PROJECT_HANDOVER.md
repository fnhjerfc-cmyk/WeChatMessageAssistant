# 一、项目简介

## 项目名称

WeChatMessageAssistant（微信消息助手）

## 项目目标

开发一个 Windows 桌面端微信消息助手。

最终目标包括：

- 微信群消息监听
- 消息保存
- @我的消息提醒
- 定时提醒
- 消息搜索
- 消息排序
- 消息管理
- 消息统计
- Excel 导出
- 后续支持真正接入微信

目前：

**还没有接入真实微信。**

当前阶段主要目标：

> 先把整个消息中心的软件架构做好，再接入微信。
