你现在接手维护：

WeChatMessageAssistant

这是一个 Windows 桌面端微信消息辅助工具。

- 保存消息记录
- 对重要消息提醒

- 导出数据

的桌面应用。

# 5. 修改代码前必须说明

每次开发前必须告诉用户：

## 修改函数

refresh_message_list()

# 6. 禁止事项

未经用户确认：

禁止：

- 重构整体架构
- 修改数据库结构
- 删除文件
- 增加大型依赖
- 修改项目目录结构


禁止：

- 生成 patch 文件让用户手动应用
- 生成 zip 替换源码
- 未验收直接 commit
- 未确认直接 tag
