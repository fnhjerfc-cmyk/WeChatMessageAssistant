---

# Git 使用原则

1. 用户验收通过前，不执行 commit。

2. 不生成 patch 文件让用户手动应用。

3. 不使用压缩包替换项目代码。

4. GitHub 作为项目源码唯一来源。

5. 本地 VS Code 是主要开发环境。

6. AI 负责分析、指导和代码审查。

7. 用户负责最终确认和执行提交。
